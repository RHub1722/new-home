# Этап 4: что отложено на следующие этапы

Итог ревью этапа 4 («Дашборд»): замечания, которые не блокировали слияние. План этапа 5 (VPS) должен их учесть.

## Перед тем как полагаться на дашборд

- **Запуск под pythonw ещё не проверен.** На копии базы дашборд запускался из консоли (`uv run homealize dashboard`). После `scripts\autostart.ps1 -Install` нужно убедиться, что:
  - открывается http://localhost:8501;
  - в `logs/dashboard.log` есть строка «Дашборд: …»;
  - телефон открывает напечатанный адрес;
  - на вопрос брандмауэра отвечено только «Частные сети».
- **Адреса для телефона.** `autostart.ps1` печатает адреса на порту 8501 при любых `dashboard.port` и `dashboard.host`. Среди них могут быть виртуальные адаптеры (WSL, Hyper-V, VPN), а при `host: "127.0.0.1"` адреса печатать вообще не нужно.
- **Сообщение о занятом порте** всегда говорит «дашборд уже запущен», даже если порт держит другая программа.
- **Ошибка открытия `logs/dashboard.log`** под pythonw не обрабатывается: процесс молча завершится при старте.
- **Трассировки видны гостям сети.** У Streamlit `client.showErrorDetails = full`: любой в домашней сети увидит трассировку с локальными путями. Можно передавать `--client.showErrorDetails type` (трассировка всё равно попадёт в `logs/dashboard.log`). На VPS (этап 5) это обязательно вместе с паролем и HTTPS.

## Страница

- **Название села повторяется:** «Яловены (Яловены)», когда район называется так же, как село. Чинить в одном месте — `fmt.place` (её использует и бот) и `market.Place.label`; в карточке брать `html.unescape(fmt.place(row))`.
- **Метки подозрительного участка** повторяют одно и то же: «подозрительно дёшево; 🔍 подозрительно дёшево — проверить вручную». Метку, совпадающую с причиной исключения, не показывать.
- **До первого прогона** обе вкладки пишут «Под фильтры ничего не подошло», хотя фильтры ни при чём.
- **Не база SQLite.** Если по пути базы лежит не база SQLite, страница падает с трассировкой на `PRAGMA user_version`, соединение не закрывается.
- **Ошибка базы при отметке.** `ui._set_mark` ловит только `MarkBusyError`: другая ошибка базы показывается трассировкой Streamlit.
- **Экранирование.** `st.error` с путём настроек и текстом исключения, а также запасная подпись статуса прогона идут мимо `plain()`. `plain()` не экранирует `:` и `&` (короткие коды эмодзи Streamlit из текста объявления сработают).
- **График истории цены** без единиц по оси и смешает валюты, если объявление сменило валюту. Можно рисовать `price_history.price_eur`.
- **Число в рейтинге** считается прямым SQL в `ui.py`.
- **Streamlit кладёт `src/homealize/dashboard` в начало `sys.path`:** модули дашборда становятся доступны и как `card`, `listings`, `market`, `ui`, `app`. Сейчас безвредно.

- **Ползунки и переключатели.** Если переключатель меняет границы ползунка (например, «Показать дороже бюджета» — цену), ползунок возвращается на весь диапазон. Так задумано: старый узкий диапазон спрятал бы только что показанные строки.
- **Карта** запоминает выбранную точку по фильтрам, а не по списку участков. После скрытия участка ботом его карточка может остаться открытой до следующего действия. Вреда нет: карточка ищется по id.

## Рынок

- **«None» в колонке изменения.** Пока нет данных четырёхнедельной давности (до конца ноября 2026), пустые ячейки колонки «За 4 нед., %» Streamlit рисует серым словом «None»: так он показывает пустое число, настройки нет. Исправление — текстовая колонка с «—» или скрывать колонку, пока в ней нет ни одного значения.
- **Настройки.** `market_compare_weeks` не ограничен сверху и не сверяется с `market_weeks`: при `compare_weeks ≥ weeks` колонка изменения всегда пустая. Нужен валидатор `market_compare_weeks < market_weeks`.
- **Деление на нулевую медиану** в `market_table` не защищено. Сейчас недостижимо: нулевая цена превращается в «без цены» ещё при разборе.
- **Производительность.** `weekly_medians` читает всю `price_history`, включая отсеянные объявления, и пересчитывается при каждом действии на странице. Если станет медленно — кэш по id последнего прогона.
- **`week_start`** молча принимает время без часового пояса.

## Карточка и отметки

- **`nearby_pois`** при каждом открытии карточки перебирает всю таблицу `poi` (3,4 тыс. объектов, десятки миллисекунд). Можно отсечь прямоугольником в SQL.
- **`load_card`** дважды читает отметки.
- **Отметка для объявления, которого нет в `listings`,** даёт `IntegrityError` (страница такую отметку поставить не может).
- **`SQLITE_LOCKED`** тоже считается «занято», хотя решение 7 называет только «database is locked». Практического эффекта нет.

## Тесты, которых нет

- **Рынок:**
  - неделя с переходом на зимнее время;
  - одноимённые сёла в разных районах;
  - объявление без села (только «Все сёла»);
  - участие дороже бюджета, дубликатов и подозрительных;
  - отрицательное изменение;
  - пустая база;
  - время ровно на границе недели.
- **Карточка:**
  - откат при ошибке (`IntegrityError` не трогает `user_marks` и `scores`);
  - `Card.hidden = True`;
  - пропуск отсутствующего компонента и цены NULL;
  - веса, отличные от умолчаний.
- **Ресурсы в тестах:** два теста карточки не закрывают соединение, если упадут раньше `finally`; тест перенаправления вывода под pythonw закрывает файл только при успехе и не проверяет случай, когда `None` только один поток.
- **Рейтинг:**
  - верхняя граница порта;
  - хешируемость `Filters`;
  - подписи для неизвестных кодов;
  - `picked_listing_id` с другим слоем.
- **CLI:** преобразование `SystemExit` в `_run_streamlit` (строковый код сейчас молча становится 1).
- **Страница:** выбор точки на карте `AppTest` не умеет — проверено только вручную в браузере. Выбор строки таблицы проверяется записью выбора в `session_state`; что браузер снимает подсветку строки после смены ключа, проверено только вручную.
- **Тест рынка** берёт текущее время: если прогон тестов попадёт ровно на границу недели по Кишинёву, он может упасть.

## Документация

- **README:** в заметке об обновлении автозапуска команда дана как `scripts\autostart.ps1 -Install`, без `powershell -ExecutionPolicy Bypass -File`, как выше в том же разделе.
- **План этапа 4** — запись того, что планировалось. Расходится с кодом в трёх местах:
  - решение 8: ключ таблицы теперь строится по списку показанных участков, а не по фильтрам;
  - докстринги `bounds`: границы теперь зависят от переключателей и цена кратна 500;
  - решение 9: в колонке изменения ожидалось «—».
